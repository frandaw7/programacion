Suponemos que el usuario introduce correctamente los datos, es decir, el número introducido tiene dos dígitos como mínimo y la posición en la que se parte el número está entre 2 y la longitud del número. | [Ver práctica.](https://github.com/frandaw7/programacion/blob/main/Tema4/QPartirNumero.java) | 🟡 En proceso. |
| **☕♨️ QInsertarDigito.** | Escribe un programa que sea capaz de insertar un dígito dentro de un número indicando la posición. Suponemos que el usuario introduce correctamente los datos. Se recomienda usar long en lugar de int ya que el primero admite números más largos. | [Ver práctica.](https://github.com/frandaw7/programacion/blob/main/Tema4/QInsertarDigito.java) | 🟡 En proceso. |
| **☕♨️ QInsertarMitadCadenaCaracteres.** | Programa que inserte “<>” justo en la mitad de una cadena de caracteres desde teclado. | [Ver práctica.](https://github.com/frandaw7/programacion/blob/main/Tema4/QInsertarMitadCadenaCaracteres.java) | 🟡 En proceso. |
